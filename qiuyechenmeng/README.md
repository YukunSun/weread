# 《艽野尘梦》阅读地图

**从这里开始 → [下载或打开《艽野尘梦》阅读地图（KMZ）](艽野尘梦_阅读地图.kmz)**

随书查看陈渠珍的行程、旧地名和任乃强校注。主地图 KMZ 已打包地图和点标图标，下载这一个文件即可开始阅读。

## 在 Google 地球中打开

1. **网页版**。在 Google 地球首页选择「新建 → 将文件导入地图项目」，然后从设备上传 KMZ。已有项目可用「文件 → 导入文件 → 从设备上传」。若弹出导入类型，选择「地图项」，导入后等页面显示已保存到 Google 云端硬盘。只想临时查看时，也可用首页的本地 KML 编辑器打开 KMZ。[Google 地球导入指南](https://developers.google.com/maps/documentation/earth/import-data?hl=zh-cn)
2. **Google Earth Pro 桌面版**。选择「文件 → 打开」，选中 KMZ。需要长期保留时，把左侧「临时地点」下的地图拖入「我的地点」。[Google 地球地点保存说明](https://support.google.com/earth/answer/148150?hl=zh-Hans)
3. **按章节阅读**。从左侧 `00` 图例与耗时总览或 `01`–`05` 正文行程开始。单击地点读旧名、今名、来源和定位说明，双击可定位。需要对读时，再勾选 `08` 小地名、`09` 现代道路、`11` 南北驿路或 `13` 河流与渡河。
4. **补充或更新**。已有主地图时，从专题目录选缺少的 KMZ 单独导入。同一图层保留一份可见版本即可。若网页版省略无坐标卡片，可在详细说明和待考地名资料中查阅。[地图使用说明](docs/地图使用说明.txt) · [待考地名](data/未定位地名.json)

地图上的「地区参照」「约位」「推定」标示现代代表点或候选范围，旧址可能仍待考。示意虚线表示地点顺序或大致方向，`km` 为代表点之间的直线距离。原书的里数、行程日数和驻留时间分别记录。

## 更新地图文件

在本书目录运行下列命令。主地图生成只使用 Python 3 标准库，读取本地数据。脚本会覆盖同名导出，主 KMZ 写回根目录，其他产物写到上表对应目录。

```sh
python3 scripts/build_map.py
```

修改小地名和地名考证可从对应数据开始。[小地名数据](data/小地名.json) · [地名核对资料](data/place_checks/)

个别专题有独立脚本，可按需重建，例如 `python3 scripts/build_republic_garrisons.py` 生成民初边军驻防图层。更新后可用 `unzip -t 艽野尘梦_阅读地图.kmz` 检查打包，再导入 Google 地球查看。
